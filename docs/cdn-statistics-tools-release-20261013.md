# CDN统计分析、高级工具与待手动处理产品

工作区版本：待发布 v0.1.109（后端）、v0.1.142（前端）。

统计分析九个三级菜单与独立路由：带宽、流量、访问、命中率、状态码、数据分布、独立IP、直播、带宽环比。带宽提供服务、回源、省份运营商视图；图表 Kumo 双滑块仅缩放已取得数据。所有查询以金山云API为源，只保留有界短时内存缓存，不建历史数据表。用户查询每次校验域名归属、验证状态、服务账户启用，缓存命中也重新校验。

高级工具：域名范围云证书查询、浏览器本地CSR与私钥生成、IP检测、自动刷新配置条件说明。CSR私钥不上传；KS3自动刷新未接入，不伪造开关；直播尚缺专用直播域名真实验收；数据分布当前图表/表格不含中国地图。证书查询限制100条，非全账户证书管理。

资源包购买页按规格选择；保留真实产品与平台订单支付。HTTPS请求包尚不支持购买，不能将模拟规格当成可售库存。价格计算器为官方大陆自然月累进阶梯估算：1000进制，15TB=3200元；不是计费写入口，不替换既有生产账单。

待手动处理产品：实名+雪花客户ID上下两行；编号+黑色 #上游订单链接新窗口人工登录；IP产品链接与Kumo复制；创建时间和每30秒更新的天时分到期倒计时。后端新增只读显示字段，精确关联实例/交付单元/供应商账单，不猜测本地订单号。多账单无法唯一关联时不输出错误链接；API路径未确认账单门户时只显示编号。无schema迁移，无退款/余额/交付/云写入改变。

本地模拟预览脚本、固定测试域名映射、测试客户不入仓库发布，不入生产。

验证证据及运行版本见 D:/ddoidc/deploy-notes 与 Obsidian 系统开发地图中的 CDN统计分析、CDN高级工具、后台待办与异常处理、安装与在线更新。
