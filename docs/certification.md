# 实名认证界面

- 用户 `/console/certification`：个人/企业方式选择、证件类型、共用国家区号组件、鉴权上传预览、一次机会确认、脱敏结果与拒绝原因。
- 管理 `/admin/certifications`：多状态筛选、请求体搜索、排序分页、完整审核详情、证件放大、通过/拒绝/解除限制与审计；实名设置位于同页 Tab。
- 个人中心增加入口；客户详情“查看”跳转对应客户审核记录。
- 订购商品、购物车结算和订单提交共用 CertificationGate，检查失败时不会继续操作，未认证时引导认证；后端仍是最终门禁。
- 管理拼团表单恢复 requireCertification 设置。

不写本地存储认证资料。完整审核查询关闭后立即释放缓存；审核成功失效客户详情摘要缓存。图片使用 Cookie 鉴权 URL。禁用企业认证时不显示入口；要求先个人认证时，遵从一次记录规则禁用企业申请并说明原因。

使用现有 Kumo 组件，没有新依赖。VM 完成 npm ci、npx tsc -b 和生产构建。真实浏览器已验证菜单、个人/企业字段及法人代表动态字段、审核筛选、详情、鉴权图片放大、拒绝与客户脱敏结果。浏览器自动选择上传文件受 Edge 扩展“允许访问文件网址”权限限制；上传及提交接口已通过真实文件/API测试，此项浏览器端完整操作尚未验收。
