# 后台客户域名统一管理

从后端 v0.1.157、前端 v0.1.179 最新 main 开发，保留既有采购与更新器修复。后台 /admin/domains（实际使用配置的随机后台入口）新增全客户域名统计、关键词/状态/到期筛选、20条分页、客户详情链接、单域名最近50笔订单及50条操作记录。统计范围不随筛选改变；pending 表示归属待确认，不表示正常可管理。
