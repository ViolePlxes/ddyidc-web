# 西部数码域名服务真实接入（2026-10-25）

## 范围与部署

基于后端 v0.1.156、前端 v0.1.178 的最新 main 合并开发，保留采购前报价安全重试与两项更新器权限修复。生产不自动安装；用户通过现有后台更新功能先更新后端再更新前端。058 为新增独立域名表及通知模板的兼容增量迁移，已登记自动迁移分类和不可变校验；不修改既有客户、实例或余额。

## 接口与归属

后端 `internal/domains` 包含固定 HTTPS West v2 客户端、GBK 编码、毫秒 MD5 协议签名、58 项审定契约、凭据加密、归属校验、订单支付、结果核对与管理导入。客户 `/api/v1/domains` 下提供 contracts/assets/templates/operations/orders/actions/quotes/reconcile。管理员 `/admin/v1/domains` 下提供 settings/operations/import/feeds，全部检查有效超级管理员；凭据不回显。全量代理域名和信息模板不能直接向客户透传；客户仅管理本地明确归属的资源。DNS 修改删除需先确认记录属于选定域名；命名失败列表按 strdomain 过滤本人资源。敏感实名上传凭证仅服务端使用，证件图仅接受 4MiB 内 JPEG/PNG。

批量交易清单为后台只读下载能力，成功 URL 仅允许 HTTPS 的 west.cn 或其子域名，不在服务端跟随任意下载地址，也不向客户暴露采购清单。未验证的其他下载域名保持拒绝。前台实时单域名详情和购买独立提供，不把操作记录冒充库存同步。

## 金融与幂等

域名价格使用精确金额类型；注册多年按首年注册成本加其余年续费成本，再应用配置加价和一次服务费。赎回缺少官方报价接口，要求管理员先核实并配置成本，零成本不允许下单。短期报价绑定本人、配置版本、金额和内容，客户端不能覆盖成本、续费原到期时间或认证字段。

创建标准平台订单和 domains 模块订单项；余额仅通过 BalanceService.Change(order_pay)，在线付款复用现有网关和持久支付任务。支付前校验报价期限与配置，采购前再次核验实际支付、金额和实时成本。相同报价重复建单复用同一订单，同一域名同一操作存在未处理订单时阻止重叠下单。

外部收费写入前提交 executing 记录，使用不自动重试的独立 HTTP 传输；响应丢失或崩溃进入 unknown，永不自动重新扣款或采购。明确受理后才进入 submitted；续费需核对实际到期增长，注册需逐域名成功而不能只看外层 200；安全锁还须实际服务状态为 1，并保留域名原到期时间。最终域名订单、标准订单、交付项及通知在同一事务完成；成功回调重放仍核对平台状态。失败和待核对保留记录、持久通知。每分钟维护仅只读核对已受理订单，孤立 executing 转 unknown，超期转人工核对。
