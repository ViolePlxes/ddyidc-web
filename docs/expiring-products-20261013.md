# 即将到期产品展示

即将到期队列仍限定未来72小时内未到期有效实例。客户显示已通过实名与新版ID两行，链接客户详情；产品编号和IP链接产品详情，IP可复制。等待时长改为到期倒计时，隐藏零值单位，每30秒刷新。

后端批量读取同客户实例到期时间、当前billingCycle与合法primary_ip；实名仅status=2。前端通过既有renewal-options GET接口取匹配当前周期的整期报价，不取旧快照金额，不折算年付为月付。并发上限3、缓存5分钟、无匹配/失败显示不可用，不自动下单或付款。

无新表/迁移/任务/余额或交付状态变动。新增TestExpiringDisplayMySQL在隔离库验收到期/周期/IP/客户归属，不将普通CI跳过计为通过。VM模拟报价及剪贴板/链接/倒计时浏览器验收通过；生产原有3条报价接口只读核验成功。模拟预览不发布。

候选后端v0.1.110、前端v0.1.143。运行版本与完整验收记录见系统开发地图及deploy-notes。
