# 真实支付展示口径

功能版本 v0.1.151，依赖后端 v0.1.121；环境实际版本与部署状态以开发地图为准。后台 Home 今日充值金额采用后端真实外部收款汇总，提示为“今日真实收款 N 笔”。余额消费本身不再次算充值。

余额流水复用现有前台 BalanceTransactions、后台 CustomerFinance 与 usePrefetchedLedger，不新增前端虚拟流水。直接外部付款由后端原子生成增加/扣减两条，刷新或客户端资金通知后获取同快照三方向页；不恢复自动轮询。历史补记保留当前追加时间与服务端审计，不在浏览器拼接假记录。

ReceiptReviews 识别 external_balance_ledger_mismatch，提示已收款但成对流水/订单未完成；提供原核查恢复动作，服务端仅有效超级管理员可恢复外部订单。弹窗使用平台 Kumo Dialog、原因必填与显式确认。重复恢复仍以后端幂等结果为准；不接入自动渠道退款。

验证需要前后端隔离真实接口、Kumo 原样式、账本两腿与净余额、首页统计及重复/异常场景。各环境实际部署结果单独记录，不把本地验收等同生产验收。

VM npm ci / npx tsc -b / npm run build 与源码、产物隔离、浏览器启动门禁通过。真实隔离接口浏览器验收：前后台 +320/-320 与 +109/-109 可见、净余额不变，每方向20行、6次切换0额外请求，手动刷新有效；390px无页面溢出。测试资金是隔离合成数据，未执行真实支付网关扣款。
