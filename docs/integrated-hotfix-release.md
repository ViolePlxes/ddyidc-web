## 整合复核补强

- 补付只有明确发送前失败证据才可归类payment_not_sent；缺失WroteRequest回调不构成安全重付证据。恢复前GET核对原账单ID及Paid/Unpaid状态，Paid不再次付款，状态不明停止。所有测试使用httptest，不连接真实供应商。
- 通知快照采用DOM解析与HTML元素/属性白名单；禁用脚本、事件、嵌入对象及外部资源，保留文本排版和经校验的普通链接。
