# 商品目录加载与恢复
范围：订购页面与公共目录读取。版本：v0.1.135。根因尚未还原，此改动修复已验证的误判与恢复缺陷，不声称客户个案已复现。
GET /api/v1/products 使用 page/pageSize 和每次加载独立的 _catalog 参数，并请求 no-cache。进页重新读取目录，失败自动重试一次。只读取本地商品目录；不增加供应商调用或采购。
catalogIntegrity.ts 校验 items/groups/total、configurable、ID 精度；安全整数 ID 归一为字符串，原字符串大整数不转换为数字。完整分页汇总后必须与 total 相等；缺页、重复页或总数变化抛错，禁止静默展示部分目录。
Products.tsx 区分加载错误、目录关联异常、当前分类无可配置商品和真正空分类；异常目录最多自动恢复一次，并提供手动重试。库存为零仍展示规格，不纳入目录为空判断。
复制诊断只包含模块、版本、时刻、总数、加载数、分组数、当前匹配数、可选数及状态。无账号、手机号、邮箱、token、URL、UA或浏览器指纹。诊断由用户主动复制交给客服；本轮未增加服务端自动收集接口。
隔离 VM：npm ci、tsc/build；node tests/catalogIntegrity.test.mjs 与 productCatalog.test.mjs 共8项通过；320x568/390x844/1440x900 Chromium 共18项通过，覆盖正常/数字ID/结构缺失/全部被过滤/自动恢复、分类切换、503故障、手动恢复与复制诊断，无JS错误、无业务写请求。
