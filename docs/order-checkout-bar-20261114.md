# 订购产品页底部结算栏（v0.1.296）

## 范围

客户控制台「订购产品」页 `/console/products`。商品详情页 `/console/products/:id`、下单确认页、支付页与后台商品管理不在本次范围；详情页只复用同一个共享底栏组件（`variant="sticky"`），交互不变。

## 布局约定：底栏固定，不悬浮

- 页面占满 `[data-dashboard-scroll]` 内容面板（`usePaneFillHeight` 实测高度，扣掉平台页脚与页面内边距），整页不再产生外层滚动。
- 页面内部为「内容滚动区 + 底栏」两行：内容区 `flex-1 min-h-0 overflow-y-auto`（`data-order-scroll`），底栏是文档流里的真实底行（`variant="inline"`），紧贴内容区与平台页脚，中间没有缝隙。
- 因此滚动只发生在内容区，**没有任何内容从底栏下方穿过**；底栏不吸顶、不悬浮、不遮盖内容。桌面展开明细时底栏变高，内容区同步变矮并重新计算行数。
- 单列内容与底栏内容列同用 `catalogContentWidth`（`max-w-[100rem]`，1600px）；比原来的 1280px 宽，让计算规格表在 1920 及更宽的屏幕上能完整展示所有列。底栏底色通栏、内容列居中，和页面内容左边缘对齐（实测 `alignGap = 0`）。
- 顶部订购步骤用 Kumo `Breadcrumbs`（`size="sm"`、`Breadcrumbs.Clipboard`），吸附在内容滚动区顶部；窄屏保留完整步骤并横向滚动，不折叠为下拉。Kumo 默认在 `sm` 以下折叠、`Clipboard` 只有英文 `title` 且无复制结果回调，已在包装组件里覆盖并接管中文 Toast / 手动复制降级。步骤轨迹由页面持有（`ProductConfig` 通过 `onSteps` 上报，页面渲染 `OrderStepsBreadcrumbs`），换分类/换规格时轨迹保持挂载、内容不变，不会回落到单步占位再展开。
- 报价刷新用 Kumo `Loader`（16px，紧挨金额、固定占位不引起位移）：改配置/换时长期间金额保留上一次已确认的报价，明细卡里的「正在更新」徽标也换成同一个 Loader；刷新不再插入「正在获取最新报价」这类会闪现的提示。
- 换分类/换规格时底栏不闪：页面保存最后一次提交的底栏快照（`barSnapshotRef`），在新配置加载期间以 `inert` 渲染快照（只读、不可点），底栏结构与金额保持不动；金额缓存通过 `amountsRef` 跨组件挂载共享，新配置首次报价期间继续显示上一笔金额并显示 Loader，不会闪成「—」。快照只在 `configLoading` 且有已选商品时使用，空分类或配置报错仍显示中性占位。
- 步骤跳转与行数测量都让出吸附条高度（`orderStepsOffset()`）；行数按内容滚动区高度实测，预留分页与安全值（`useFillingPageSize` + `fillingRowCount`，3–50 行），保留页码分页。
- 明细：用 Kumo `Popover` 在「查看明细」上方弹出（`side="top"`，宽 24rem、`max-h: min(70vh,32rem)` 内部滚动，最高不超过视口）。鼠标悬浮触发器自动展开、移入弹层保持、移出 150ms 后关闭；触屏点按开合，`Escape`/点击外部关闭。弹层内只显示账单信息（当前应付、单台本周期、规格与配置、周期、数量、折合月费、下次续费、安装费与报价提示），购买数量控件、加入购物车、立即购买均已移出。商品详情页仍用原有 dialog + 账单卡，交互不变。
- 底栏操作（参照站点通用结算栏）：从左到右为「订购时长」+ 紧凑 `Select`、「订购数量」+ Kumo Pagination 样式的数量控件（`InputGroup`：`−` / 可直接输入的数字 / `+`，输入框居中 44px 宽，回车或失焦收敛到 1–10）、`当前配置` 下划线链接（悬浮/点击打开明细弹层）、1px 分隔线、「配置费用」+ 红色金额（`text-kumo-danger`，24px，≥1600 时附加折合月费）、购物车图标按钮、`立即购买`（`Button variant="primary"`，禁用时 50% 透明）。时长、数量、购物车均为 36px 高，整行元素垂直居中于同一中轴；数量与时长变化实时更新金额与明细弹层。阻断原因以红色小字显示在栏内。站点暂无优惠码后端，因此未放「使用优惠码」。订单页的「购买信息」卡不再重复放时长选项卡，商品详情页仍在卡内用分段选项卡。

## 计算规格表格固定列

- `ConfigurableTable` 新增可选 `stickyEdges`：首列（实例规格）固定在表格容器左侧、末列（参考价格）固定在右侧，中间列在表格容器内横向滚动；仅订购页的计算规格表启用，其它表格不受影响。
- 固定列使用 Kumo `Table.Head` / `Table.Cell` 的 `sticky="left"|"right"`（自带不透明行背景、内侧渐变和层级）；隐藏/拖动调整列后按当前可见列重新取首末列。
- 注意：表头单元格不能再写 `relative`（会覆盖 Kumo 的 `sticky`，固定列会跟着表格滚走），`TableColumnHead` 因此在 `sticky` 时不加 `relative`，列宽拖动条仍以 sticky 单元格为定位父级。
- 固定列背景必须和整行一致：共享表格样式把行背景统一为 `bg-kumo-base`（悬停为 `bg-kumo-overlay`），因此同时把 Kumo 的 `--kumo-table-row-bg` 覆盖为同一表面（含 `even` 行与悬停态，`!` 优先级压过 Kumo 的斑马/选中变体）。否则固定列会单独出现 `kumo-elevated` / `kumo-tint` 的浅灰，看起来像给列加了颜色。没有新增任何自定义色值，全部沿用 Kumo token。
- 裁切分界：表格默认按页面可用宽度展示全部列（容器够宽时表格拉满容器，不出现横向滚动、不显示分界竖线）；只有确实放不下（`scrollWidth > clientWidth`）时，首列右缘与末列左缘才显示 1px `kumo-line` 分界竖线并启用左右固定。分界线随滚动位置收放：滚到最左时左侧竖线消失，滚到最右时右侧竖线消失（该侧已没有内容藏在固定列下面）。分界线与表头的列宽拖动线重合——拖动线由居中改为贴列边界（`justify-end`，8px 热区不变），避免出现两条线。
- 滚轮横滑：表格可横向滚动时，在表格（中间区域）上滚动鼠标滚轮即可左右滑动；`Ctrl`（缩放）、`Shift`（原生横滑）和触控板横向手势保持浏览器原生行为；滚到最左/最右后继续滚动，页面恢复正常上下滚动（不劫持滚轮）。

## 复制摘要

`Breadcrumbs.Clipboard` 复制内容含商品、规格、配置、周期、数量、当前应付（含折合月）与生成时间，末尾固定「金额为页面实时报价，以提交时校验结果为准。」。金额与底部栏同一来源（`total` / `monthlyEquivalent`），缺项整行省略；成功后用 Kumo `Toast` 提示，剪贴板不可用时选中文本并提示手动复制。

## 复用与边界

- 复用：`useProducts` / `useProduct` / `useOrderPage`、`ProductConfig` 的报价/周期/数量/密码/认证/购物车/`draft()`、`saveOrderDraft`、`catalogStock`、`isCatalogAvailable`、`cycleLabels`、`scrollToProductStep`、Kumo `Breadcrumbs` / `LayerDialog` / `Toast` / `Pagination`。
- 未改：报价与下单接口、认证门禁、购物车、订单草稿、后端、数据库；未新增第三方依赖。
- 按钮口径沿用 `ProductConfig` 原有 `purchaseDisabled` 与 `barBlockedReason`；未选规格时底栏显示占位并禁用按钮。

## 验证（本地）

- `npx tsc -b`、`npm run build`、`node scripts/check-release.mjs` 与 `--artifact` 通过；`tests/fillingPageSize.test.mjs` 已纳入 CI。
- 本地 mock API + 真实 Chromium（Edge headless）在 360×800、390×844、768×1024、1280×900、1600×1000 实测：内容面板外层滚动 `0`，内容区内部滚动，底栏底边紧贴平台页脚（间隙 `0`），底栏顶边紧贴内容区（间隙 `0`），左边缘对齐 `0`；1280/1600 行数 6/8，底栏 65/80px；页面与内容区横向溢出均为 0（改造前 1280/1600 面板横向溢出 715/395px）。
- 交互：步骤跳转与吸附、分页翻页、明细展开/收起（内容区变矮、行数 6→3、无遮挡）、复制摘要（含金额与 Toast）、报价联动、密码不合规禁用与原因、分类切换、空分类、移动端抽屉均通过；1024/853 缩放代理无横向溢出，触控目标 44px。
- 固定列：1280 下表格容器 941px、表格内容 1520px；横向滚动到 290/579 时，首列（含「字段」按钮）始终贴容器左边、末列（参考价格）贴右边，表头与数据行同步固定，中间列在容器内滚动；页面与内容区横向溢出仍为 0。像素核对：普通行与悬停行的首/中/末列颜色一致（255,255,255 / 251,251,251），没有单独给固定列或行加色。
- mock 数据仅用于本地验收，不进入源码、构建产物或生产配置；生产安装由管理员在后台执行后按测试矩阵复核。
