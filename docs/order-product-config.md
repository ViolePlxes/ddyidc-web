# 订购商品配置展示

## 展示约定

- 商品参考价只显示金额，不追加“/ 月付 起”；右侧账单仍显示购买周期、应付及续费价格。
- 订购步骤位于内容顶部，桌面端窄栏固定；计算规格的 Windows/Linux 图标仅展示，不改变镜像或规格选择。
- 资源配置使用固定来源的 Kumo 官方 Slider small 实现（见 `src/shared/vendor/kumo-slider/README.md`）。规格标题在滑条上方，加减按钮分列两侧并与轨道居中对齐。
- 数值和单位跟随滑块显示。2–4 个可选位置显示灰色分段刻度；其余显示两个端点。选中位置隐藏对应刻度或端点，移开恢复，保持占位。
- 配置名称和摘要中的零元费用文字隐藏，非零费用保留。展示清理不改变原配置 ID、数量、价格、订单草稿或提交金额。

## 数据与发布边界

仅改前端展示，复用已有商品与配置接口，不增加后台写入接口或数据库迁移。
本地示例商品服务器位于仓库外，只在隔离 VM 中提供内存数据，拒绝写请求；不纳入源码、构建产物或生产配置。

发布前在隔离 VM 执行 npm ci、TypeScript、生产构建、浏览器恢复测试及 source/artifact 发布策略检查；浏览器核对拖动、加减、端点、分段刻度、报价联动和系统图标的展示行为。
生产只通过平台在线前端更新安装，不更新后端。
