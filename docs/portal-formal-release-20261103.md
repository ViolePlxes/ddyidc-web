# 官网正式内容与旧浏览器兼容合并更新（2026-11-03）

## 内容与行为

官网使用已确认首页、共享头尾和阿里云参考营销布局；后台使用原Kumo编辑器。正式内容包括平台介绍、联系/工单、计算/域名/分发/账户安全、解决方案、推广合作、合作咨询、活动入口和6篇真实操作指南。未编造公告、价格、公司地址、资质、合作伙伴或岗位。资质/许可/环境/伙伴/招聘/AUP无核实材料时保持隐藏。服务/隐私正文沿用仓库现有协议，不在本次新建退款承诺或法律政策。

底栏按用户最新截图保留：开始使用、平台服务、资源与支持、解决方案四列，加右侧联系区；共享组件维护一份。品牌多多云，底部域名ddoidc.com。保留首页尺寸、交互与两个已隐藏区块。

合并 github-package-20261103-browser-allow 的两份补丁：旧内核仅按运行时能力硬拦截，现代CSS能力缺失允许降级；CSS实际未加载/模块失败仍有恢复面板。Node守卫测试覆盖缺CSS.registerProperty/现代颜色但允许运行、运行时缺失拒绝、CSS和utility缺失、资源失败、超时及手动恢复。不保证旧360/QQ所有样式完整，未虚称真实旧版本浏览器均已验收。

## 更新后的内容发布

代码更新不会自动发布或覆盖管理员的未确认草稿。更新前端和后端后，在后台“前台内容 → 官网页面管理”点击“应用正式官网内容到草稿”，预览，再“发布站点”。此准备接口只返回建议文档，版本不递增、无DB写入；最终仍走原保存/发布/审计/回滚。

正式包补齐缺页、替换已识别演示/空白/原始seed内容、移除已知演示文章。保留已有有效自定义内容与首页模块；无法核实的企业资料不凭空生成。旧站点也可直接使用此入口，不需删库或重新安装。源数据唯一位于后端internal/portal/formal_content.json。

新增POST /admin/v1/portal/formal-draft，沿用超级管理员鉴权；正式公开GET /api/v1/portal/content同发布版本提供页面、菜单和分类。Page.layout、Link.description/enabled可选，旧schemaVersion=1兼容。安装顺序后端优先，前端随后；无需生产DDL。
