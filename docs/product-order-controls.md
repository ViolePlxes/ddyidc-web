# 订购页分类与资源控件

一级分类和二级分类分别占一行；每行文字与具体选项同排，选项按内容宽度显示，窄屏只在该行横向滚动。共享ProductCategories沿用原有分类/规格选择回调，切换仍清除旧商品选择及页码。

资源实际可选档位不超过6个时使用Kumo Radio segmented，更多档位保留既有Slider。数量型按min/max/step计算点数，不把价格阶梯当作可选数；小数步长避免漏项。保留原选项ID/数量、固定数量资源禁用及原报价/订单接口。分段外层p-1避免overflow-x-auto裁切Kumo原生ring/shadow；不自绘边框颜色。

CI新增资源档位与分类回归。预览入口、预览JSON和测试会话不属于发布源码或产物。本改动不涉及后端、数据库迁移、真实支付或机器操作。
