# SK 内容编辑器扩展

SK 菜单中原先的待接入入口现在可实际编辑门户内容，新增接入23个入口，保留完整菜单、Kumo样式、顶部层级、草稿保护和发布确认。

支持首页轮播与图文、资质环境和介绍页面、页面创建/SEO、菜单显示、活动内容列表及富文本、公开产品选择与数量、已安装主题、收录基础设置。产品模块按配置选择公开商品并避免重复追加全量目录。新页面默认隐藏；修改均先进入草稿，显式发布后才公开。

Html入口使用受校验的结构化富文本，不开放任意HTML/脚本执行。活动仅管理内容页面，未增加折扣引擎或自动上下线；推广/面板等为介绍内容。收录基础设置不主动推送搜索引擎，主题只选择已安装目录。共60个入口中35个接入编辑器，25个待接入；不宣称完整SK业务全部完成。

验证：开发VM npm ci、12项菜单/层级/路径/创建/商品ID回归、TypeScript、生产构建、发布产物门禁通过；既有后端portal测试使用新dist通过，3个合成模板场景验证商品顺序/数量/空态。18项两批隔离HTTP检查覆盖保存回读、隐藏草稿、权限、安全预览与危险内容拒绝；浏览器验证轮播保存回读、公司页创建、活动富文本/预览/列表与主题目录。QA商品目录为空，商品选择语义用合成模板测试覆盖，未操作真实采购或支付。

发布仅前端v0.1.194；后端保持v0.1.161，依赖已交付的portal接口和moduleProducts模板函数。无新增DDL、配置或迁移步骤。当前旧后端若尚未安装v0.1.161，应先完成该已有后端更新。生产安装由用户在后台手动执行，不包含本地合成验收数据或暂停的产品列表列配置。
