# 用户中心支持入口

本版本在用户中心顶部新增工单支持入口，统一跳转 `/console/help`。默认工单中心入口及旧导航中的 `/console/tickets` 入口映射到支持页，工单列表仍可通过支持页进入。

支持页采用 Kumo 卡片，桌面两张主入口加三张辅助入口；移动端单列。悬浮参照 Cloudflare 实际页面：边框加深、图标透明度提升、箭头右移 4px，背景与卡片尺寸保持不变。AI、举报、社区专用页面保留真实未开放提示。

社区区域保留全宽纹理和上下分隔线，左侧加入群聊、账户消息、云产品入口，中间绘制 QQ 群 SVG 二维码，右侧保留线条图标。二维码使用既有 qrcode 矩阵、M 纠错、四模块静区，无图片或第三方二维码生成请求；透明背景，颜色跟随 Kumo 主题。加入群聊按钮和二维码使用同一公开链接。

创建工单先选择后台实际配置的类型，再填写标题、关联产品、描述和附件。返回类型选择保留当前草稿。没有新增分类或改变创建、上传接口及原字段校验。

实现路径：`src/apps/console/views/SupportCenter.tsx`、`Tickets.tsx`、`src/layouts/DashboardLayout.tsx`、`src/apps/console/ConsoleApp.tsx`、`src/shared/hooks/useNavigation.ts`。

发布仅涉及前端；不修改数据库、余额、订单、实例、工单配置或后端。演示服务器与测试夹具保存在仓库外，不随发布包交付。
